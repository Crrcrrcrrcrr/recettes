# Référentiels recettes

Ces fichiers servent de source de vérité pour éviter les doublons lors des futurs imports.

- referentiels/categories.json : arborescence validée des catégories + alias des anciens libellés.
- referentiels/ingredients.json : ingrédients standardisés issus du master actuel.
- referentiels/unites.json : unités standardisées + alias à harmoniser.

Règle d’ajout : toute nouvelle recette doit être comparée à ces référentiels avant validation.
